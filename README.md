🚀 Features

- **Product Listing** – Displays all available products in a clean and responsive grid.
- **Add to Cart** – Users can add products to their shopping cart.
- **Remove from Cart** – Remove individual items easily.
- **Cart Quantity Update** – Real-time cart count and total amount.
- **Responsive UI** – Works smoothly on mobile, tablet, and desktop.
- **Fast Loading** – Built using React's efficient rendering.

---

🧰 Tech Stack

- **Frontend**: React.js, JavaScript (ES6+), HTML5, CSS3
- **Styling**: CSS / Tailwind CSS
- **Tools**: Vite / Create React App
- **Version Control**: Git & GitHub

⚙️ Installation & Setup
**Clone the repository**
git clone https://github.com/your-username/e-cart-app.git
cd e-cart-app

**Install dependencies**
npm install

**Start development server**
npm run dev

---

🧩 How It Works

- The app fetches product data from a local JSON or static array.
- State is managed using React hooks (useState, useEffect).
- Cart data updates instantly with every action.
- Components are modular and reusable.
